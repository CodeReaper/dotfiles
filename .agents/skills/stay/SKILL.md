# Stay

The names of the ancestor directories in the path to the working directory may sound relevant to what you are wanting to explore or research, but you should stay put.

Unless an exception applies, do not access the out-of-scope path or request expanded access. If excluding it affects the task, briefly tell the user which path was excluded.

The exceptions are:

- Access to the directory is already allowed by agent configuration
- The user explicitly asked for the directory
- The user explicitly asked for files within the directory
