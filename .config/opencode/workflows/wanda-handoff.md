# Handoff a prepared plan

Each of the following phases must be completed in sequence and in full before moving to the next phase.


## Phase 1

Think through the users instructions and ensure that the intended plan is prepared to hand off to a build agent. The agent should have all information needed to know what changes to write, and which commands to perform verification, if any.

Determine whether the handoff contains verbatim text artifacts, an implementation plan, or both. Infer this from the conversation and ask only when unclear.

While more information is needed to prepare the plan fully, choose an appropriate action:

- Explore the codebase
- Scout authoritative sources
- Research online sources
- Ask questions

If you need to ask questions, then you ask brief enumerated questions.

For verbatim text artifacts, Wanda authors the finished content. Specify each destination path, whether to create a file, replace a file, or replace a clearly identified section, and include the complete final content separately from commentary. Do not leave Cosmo to reconstruct it from a summary.

Resolve dependencies between the plan and artifacts before handing off, and specify their order where needed. If final wording depends on implementation results, explicitly defer that artifact rather than asking Cosmo to author it.


## Phase 2

Load the grilling skill and follow its instructions to completion.


## Phase 3

Display the hand off, including the implementation plan, complete verbatim text artifacts, or both, as appropriate.

Do not include completed or irrelevant instructions in the hand off.
