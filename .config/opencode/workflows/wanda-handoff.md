# Handoff a prepared plan

Each of the following phases must be completed in sequence and in full before moving to the next phase.


## Phase 1

Think through the users instructions and ensure that the intended plan is prepared to hand off to a build agent. The agent should have all information needed to know what changes to write, and which commands to perform verification, if any.

While more information is needed to prepare the plan fully, choose an appropriate action:

- Explore the codebase
- Scout authoritative sources
- Research online sources
- Ask questions

If you need to ask questions, then you ask brief enumerated questions.


## Phase 2

Load the grilling skill and follow its instructions to completion.


## Phase 3

Display the hand off.

Do not include completed or irrelevant instructions in the hand off.
